# Data Structures and Algorithms in C

A curated collection of fundamental data structures and algorithms implemented in C, aimed at reinforcing core programming concepts and enhancing problem-solving skills.

---

## 📁 Repository Structure

The repository is organized into directories, each representing a specific data structure or algorithm category:

* **LinkedLists/**: Implementations of singly and doubly linked lists.
* **Stacks/**: Stack operations using arrays and linked lists.
* **Queues/**: Queue implementations, including circular queues.
* **Trees/**: Binary trees, binary search trees, and traversal algorithms.
* **Sorting/**: Common sorting algorithms like bubble sort, quick sort, and merge sort.
* **Searching/**: Linear and binary search techniques.([GitHub][1])

---

## 🚀 Getting Started

### Prerequisites

* C Compiler (e.g., GCC)
* Basic understanding of C programming([GitHub][1])

### Compilation and Execution

Navigate to the desired directory and compile the `.c` files:

```bash
gcc filename.c -o output
./output
```



Replace `filename.c` with the specific file you wish to compile.
